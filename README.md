Live fixture used to exercise the VegaSec continuous-watch loop end to end against a real
public repository.

`contracts/WatchVault.sol` is the monitored source. It is not a product, it holds no value,
and commits here are test changes.

Monitoring target: `JE4NVRG/vegasec-watch-fixture` (repository watch, source
`contracts/WatchVault.sol`).
